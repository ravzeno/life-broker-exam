# Life Broker Exam

เว็บฝึกทำข้อสอบนายหน้าประกันชีวิต สุ่มสอบ 100 ข้อต่อรอบ เวลา 2 ชั่วโมง 30 นาที พัฒนาด้วย React และ Vite

ติดตั้ง Node.js แล้วรัน `npm ci` และ `npm run dev` เพื่อเปิดเว็บในเครื่อง ใช้ `npm run build` เพื่อสร้างเว็บไซต์ static ในโฟลเดอร์ `dist` และ `npm test` เพื่อตรวจชุดทดสอบ

แต่ละรอบสุ่มจรรยาบรรณ 10 ข้อ ความรู้ประกันชีวิต 50 ข้อ ประมวลกฎหมายแพ่งฯ 20 ข้อ และ พ.ร.บ. ประกันชีวิต 20 ข้อ คิดข้อละ 2 คะแนน ผู้สอบผ่านเกณฑ์จำลองเมื่อจรรยาบรรณได้อย่างน้อย 14/20 คะแนน และวิชาชีพกับกฎหมายอีกสามหมวดรวมกันได้อย่างน้อย 108/180 คะแนน

ข้อสอบสุ่มลำดับคำถามและตำแหน่งตัวเลือกเมื่อเริ่มสอบใหม่ โดยข้อที่มีข้อความอ้างถึงตัวเลือกอื่นจะคงลำดับและตัวอักษรตัวเลือกเดิม รอบสอบที่บันทึกไว้ก่อนอัปเดตยังคงลำดับเดิม หน้าผลสอบแสดงคะแนนแยกตามหมวด

คำตอบ ลำดับข้อ และเวลาสอบบันทึกใน localStorage ของเบราว์เซอร์บนอุปกรณ์นั้น การล้างข้อมูลเว็บไซต์หรือเปลี่ยนเบราว์เซอร์จะทำให้ข้อมูลที่บันทึกไว้หายไป

## สถานะเนื้อหา

คำถามอ้างอิงเอกสารประกอบการบรรยายติวสอบนายหน้าประกันชีวิต ฉบับ 4 เมษายน 2567 ของสถาบันประกันภัยไทย ตัวอักษรและตัวเลือกที่ผิดจากการดึงข้อความได้รับการแก้ไขบางส่วน แต่ยังควรตรวจทานกับต้นฉบับ เฉลยที่แสดงเป็นเฉลยตามเครื่องหมายในเอกสารฉบับนี้ ข้อ 90 ใช้คำตอบที่ขีดเส้นใต้ในเอกสารแต่มีความกำกวม ส่วนข้อ 117 อนุมานคำตอบจากเนื้อหาเพราะเอกสารไม่ได้ขีดเส้นใต้เฉลย ทั้งสองข้อควรตรวจทานเพิ่มเติม เอกสารนี้เป็นข้อมูลปี 2567 ควรตรวจสอบกฎหมายและเกณฑ์การสอบปัจจุบันจาก คปภ.

ข้อมูลข้อสอบอยู่ใน `questions.js` แต่ละข้อมี `question`, `options`, `subject`, `page` และ `answer` โดย `answer: null` หมายถึงยังไม่มีเฉลยที่ตรวจสอบได้ ส่วนหมายเลขตัวเลือกเริ่มจาก 0

GitHub Actions ใน `.github/workflows/ci.yml` ตรวจสอบชุดทดสอบและ build เมื่อ push หรือเปิด pull request ส่วนการเผยแพร่ใช้ Vercel: นำเข้า repository ใน Vercel โดยใช้ framework preset Vite, build command `npm run build` และ output directory `dist` การ deploy ต้องเชื่อม repository และตั้งค่าใน Vercel ก่อน

## บัญชีและประวัติสอบ

สามารถสอบแบบ Guest ได้โดยไม่ต้องตั้งค่า โดยประวัติจะอยู่ในเบราว์เซอร์เครื่องนั้น เมื่อเชื่อม Supabase แล้ว ผู้ใช้สามารถสมัครด้วยอีเมลและรหัสผ่าน หรือเข้าสู่ระบบด้วย Google และเปิดประวัติรวมถึงรอบสอบที่ยังไม่เสร็จจากหน้าประวัติบนอุปกรณ์อื่นได้ ปุ่มคัดลอกประวัติ Guest จะคัดลอกจากเบราว์เซอร์ปัจจุบันเข้าสู่บัญชีโดยไม่ลบข้อมูลเดิม

ดูขั้นตอนตั้งค่าฐานข้อมูล สิทธิ์ RLS, Google OAuth, อีเมล และค่าที่เปิดเผยได้ใน [คู่มือตั้งค่า Supabase](docs/supabase-setup.md) ระบบบัญชียังใช้งานไม่ได้จนกว่าจะตั้งค่าโปรเจกต์จริง โปรเจกต์ Supabase แบบ Free ไม่มี backup อัตโนมัติ ควรมีแผนสำรองข้อมูลก่อนนำไปใช้งานจริง

ข้อมูลที่บันทึกออนไลน์ไม่สำเร็จจะรอซิงก์ในเบราว์เซอร์เครื่องเดิม ผู้ใช้ควรซิงก์ให้สำเร็จก่อนเปลี่ยนอุปกรณ์ และไม่ควรทำข้อสอบรอบเดียวกันพร้อมกันหลายอุปกรณ์ เพราะข้อมูลที่บันทึกภายหลังอาจทับข้อมูลเดิม คะแนนเป็นข้อมูลสำหรับฝึกสอบส่วนตัวและไม่ใช่ผลสอบที่รับรองอย่างเป็นทางการ

**เมื่อเปลี่ยนโดเมนเป็น Vercel:** ข้อมูล Guest ที่เก็บในเบราว์เซอร์ของเว็บไซต์โดเมนเดิมจะไม่ย้ายข้ามโดเมนโดยอัตโนมัติ ข้อมูลเก่ายังคงอยู่ที่เว็บไซต์เดิมจนกว่าจะถูกล้าง หากเว็บไซต์เดิมรองรับการเชื่อมบัญชีแล้ว สามารถซิงก์ประวัติก่อนเปลี่ยนโดเมนได้ มิฉะนั้นต้องเตรียมวิธีย้ายข้อมูลจากเว็บไซต์เดิมแยกต่างหาก
